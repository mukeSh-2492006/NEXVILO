# NEXVILO Prototype

A responsive product discovery and comparison prototype.

## Run
No build tools are required.

1. Keep `index.html`, `styles.css`, and `app.js` in the same folder.
2. Open `index.html` in a browser.
3. The prototype uses mock data, so no backend or database is required.

## Included
- Home
- Product search
- Category filters
- Product cards
- Price, rating, review count
- Quality and value scores
- Add to Compare
- 2–3 product comparison
- Best Value recommendation
- Recommendations
- Reviews
- About
- Contact form
- Responsive mobile/tablet/desktop UI

## Future backend
The frontend can later be connected to:
- React
- Node.js + Express
- MySQL

Suggested tables:
- products
- categories
- reviews
- users
- comparisons

## Prototype note
The product data is illustrative mock data for demonstration. It is not real market/review data.
